## 1. 一句话总结创新点

WAM-TTT 在世界动作模型的视频分支加入可适应的快权重记忆，通过人机配对元训练使该记忆能服务机器人控制，再于部署时仅用人类视频的自监督损失更新快权重，将演示信息转化为可复用的行动引导。

## 2. 摘要翻译

将机器人基础模型引导到新的任务变体或用户偏好的行为仍然具有挑战，往往需要额外的机器人示范、任务专用微调或长上下文条件。我们提出 WAM-TTT，一种利用原始人类视频引导世界动作模型的测试时训练框架。WAM-TTT 不把人类视频视为需要模仿的轨迹，而是通过自监督视频预测，把视频信息吸收到冻结 WAM 内的轻量自适应记忆中。为了使这种记忆有助于控制，我们引入元训练阶段，利用人机配对数据和键值记忆重建目标，将人类演示与机器人行为对齐。测试时，只需要无标注的人类视频即可适应记忆，预训练 WAM 保持冻结。这使得模型能够高效、可复用地接受引导，无需机器人动作、人类侧标注或任务专用微调，同时保留基础模型的泛化能力。广泛实验表明，在多种操作任务与泛化设置中，WAM-TTT 一贯优于基于上下文的人类视频条件基线。

**术语备注**：摘要的“无需任务专用微调”不等于“没有梯度更新”；测试时确实训练快权重，冻结的是 WAM 主体、慢投影和快权重初始化参数。

## 4. Method 详细逻辑

### 4.1 图示与数据流

![图1所在页](/assets/img/paper-notes/2026-09-17-wam-ttt-paper-note/316f01b38b12-page-01.png)

**图 1 图注翻译（p.1）**：给定来自多种环境的无标注人类示范，WAM-TTT 无需重定向、机器人动作或人类侧标注，就能引导一个预训练 WAM。部署时，通过自监督视频预测将人类视频吸收到轻量的 TTT 快权重中，预训练动作模型保持冻结；适应后的记忆通过 WAM 共享的视觉—动作动力学引导机器人执行，实现高效且可复用的人类示范引导。

**正文相关解释（§1，p.2）**：人类视频用于学习部署时记忆，而非转成可执行的人类轨迹。由于 WAM 联合建模视觉动态和动作，记忆对视觉表征的改变能影响动作输出；先用人机配对元训练，使这种适应有助于控制，部署时再使用人类视频。

![图2所在页](/assets/img/paper-notes/2026-09-17-wam-ttt-paper-note/2e06f37ab938-page-03.png)

**图 2 图注翻译（p.3）**：先用人机配对示范元训练快权重记忆，通过键值记忆重建目标促使人类视觉线索与机器人行为对齐；测试时通过无标注人类视频的视频预测来适应记忆，预训练 WAM 保持冻结；随后适应后的记忆经由共享视觉—动作动力学引导机器人执行。

**正文相关解释（§3，pp.4–5）**：LDA 每个 diffusion transformer block 有视频专家和动作专家，二者通过联合注意力通信。新增 TTT 分支只向视频流添加残差；当前层动作输出虽然没有直接加残差，下一层仍能通过跨流交互受到改变后的视频流影响。

### 4.2 符号与视频残差

| 符号 | 含义 |
|---|---|
| $\Theta_{\rm WAM}$ | 预训练 WAM 主体参数 |
| $z^{(\ell)},x^{(\ell)}$ | 第 $\ell$ 层视频、动作 token |
| $\theta_{K,V,Q,O}^{(\ell)}$ | TTT 的慢投影参数 |
| $W_i^{(\ell)}$ | 内环第 $i$ 次更新后的快权重 |
| $W_{\rm init}^{(\ell)}$ | 外环学习出的快权重初始化，本身属于慢参数 |
| $K_h,V_h,Q_r$ | 人类键、值与机器人视频查询 |
| $B,L_h,d$ | batch、人体视频 token 数、每头特征维度 |

$$z^{(\ell+1)}=\hat z^{(\ell+1)}+\Delta z_{\rm TTT}^{(\ell)},\quad x^{(\ell+1)}=\hat x^{(\ell+1)}.\tag{1}$$
$$\Delta z_{\rm TTT}^{(\ell)}=\theta_O^{(\ell)} f_{W^{(\ell)}}\big(\theta_Q^{(\ell)}(z^{(\ell)})\big).\tag{2}$$

备注：$\hat z,\hat x$ 是原 WAM block 的输出；$\theta_Q$ 把视频 token 映射为查询，快权重网络返回记忆信息，$\theta_O$ 投影回原隐藏维度后相加。保留主权重不变并不意味着行为不变。

### 4.3 内环：将人类视频写进快权重

$$K_h=\theta_K(h_\phi),\quad V_h=\theta_V(h_\phi),\quad Q_r=\theta_Q(z_r).$$
$$\mathcal L_{\rm KVM}^{(\ell)}(W_i)=\frac{1}{BL_hd}\left\|f_{W_i^{(\ell)}}(K_h^{(\ell)})-V_h^{(\ell)}\right\|_2^2.\tag{3}$$

备注：目标是“给人类 key，重建对应 value”。对 token 张量，该平方范数表示所有元素平方和，除以元素数得到 MSE；它本身没有机器人动作标签。

$$\mathcal L_{\rm adapt}(W_i)=\mathcal L_{\rm vg}^{\rm human}(u_h;\Theta_{\rm WAM},\theta_{\rm TTT},W_i)+\lambda\sum_\ell\mathcal L_{\rm KVM}^{(\ell)}(W_i).\tag{4}$$
$$W_{i+1}^{(\ell)}=W_i^{(\ell)}-\eta\nabla_{W_i^{(\ell)}}\mathcal L_{\rm adapt}(W_i),\quad W_0=W_{\rm init}.\tag{5}$$

视频预测损失和 K/V 重建共同更新快权重。视频损失对 $W$ 的依赖来自式 (2) 残差沿整个网络传播，并非只在某个独立 K/V 表上做回归。

### 4.4 外环：让适应后的人类记忆对机器人有用

$$\mathcal L_{\rm meta}=\mathcal L_{\rm WAM}^{\rm robot}.\tag{6}$$

机器人端使用经过内环适应的 $W_N$，计算继承自 LDA 的视频与动作扩散/flow-matching 多任务损失；反向传播穿过内环更新，训练 $\Theta_{\rm WAM}$、$\theta_{K,V,Q,O}$、$W_{\rm init}$。每个训练样本之后丢弃临时 $W_N$，重新从初始化开始。

**【补充推导｜非原文】内外环为什么不是各练各的。** 记所有慢参数为 $\vartheta$，单步适应 $W_1=W_{\rm init}(\vartheta)-\eta\nabla_W\mathcal L_h(W_0,\vartheta)$，则链式法则给出

$$\frac{d\mathcal L_r(W_1,\vartheta)}{d\vartheta}=\frac{\partial\mathcal L_r}{\partial\vartheta}+\left(\frac{\partial W_1}{\partial\vartheta}\right)^\top\nabla_{W_1}\mathcal L_r.$$

第二项让慢参数被训练成“在人类视频上更新一次后，机器人端会更好”。若省去这条导数路径，就不是原文描述的完整元梯度训练；实际二阶/近似实现应核对代码。

人机配对采用归一化阶段 $\phi=t/T_r$，取人类长度 $T_h$ 中最近阶段帧。**【阅读备注】** 这只是假设同任务演示在归一化时间上足够对齐，不等价于 HOST 的学习式任务进度对齐；不同速度或停顿仍会造成误配。

### 4.5 测试时更新与 ICL 的区别

$$\mathcal L_{\rm TTT}(W_i)=\frac{1}{|\mathcal B_h|}\sum_{u\in\mathcal B_h}\left[\mathcal L_{\rm vg}(u;\Theta_{\rm WAM},\theta_{\rm TTT},W_i)+\lambda\sum_\ell\mathcal L_{\rm KVM}^{(\ell)}(u;W_i)\right].\tag{7}$$
$$W_{i+1}^{(\ell)}=W_i^{(\ell)}-\eta\nabla_{W_i^{(\ell)}}\mathcal L_{\rm TTT}(W_i).\tag{8}$$
$$a_{t:t+k}\sim p_{\Theta_{\rm WAM},\theta_{\rm TTT},W_N}(a_{t:t+k}\mid o_t,g).\tag{9}$$

备注：$g$ 是目标条件。部署时慢参数全部冻结，只有 $W_i$ 更新；完成适应后 $W_N$ 在机器人 rollout 中也固定。人类视频存在于快权重记忆中，而 ICL 基线把视频作为上下文 token，不执行这类梯度更新。

| 阶段 | WAM | 慢投影 / 初始化 | 临时快权重 |
|---|---|---|---|
| 元训练内环 | 作为常量参与当前内环 | 作为常量参与当前内环 | 人类损失更新 |
| 元训练外环 | 机器人损失更新 | 机器人损失更新 | 作为可微中间结果，随后重置 |
| 测试时适应 | 冻结 | 冻结 | 人类损失更新 |
| 执行 | 冻结 | 冻结 | 固定为适应结果 |

### 4.6 附录 A 的注意力解释：补完线性推导及边界

原文想用快权重代替显式的人类 K/V cache；普通注意力读出为

$$\operatorname{Out}(q)=\sum_{i=1}^{L_h}\frac{e^{q^\top k_i}}{\sum_j e^{q^\top k_j}}v_i.\tag{A.1}$$

**【补充推导｜非原文中间步骤】** 暂只看线性 $f_W(q)=Wq$、固定的 $K,V\in\mathbb R^{L_h\times d}$，将式 (3) 的常数写为 $c=1/(BL_hd)$：

$$J(W)=c\|KW^\top-V\|_F^2,\qquad\nabla_W J=2c(WK^\top K-V^\top K).$$
$$\nabla_WJ=0\Rightarrow WK^\top K=V^\top K\Rightarrow W^*=V^\top K(K^\top K)^{-1}.\tag{A.2}$$

补充原因：原文直接给出闭式解；这里补上最小二乘正规方程。条件是 $K^\top K$ 可逆，即列满秩。秩亏时可用 Moore–Penrose 伪逆给最小范数解；若额外加入岭正则 $\rho\|W\|_F^2$，则逆变为 $(K^\top K+(\rho/c)I)^{-1}$，但这是补充方案，不是论文已实现的损失。

若再假设键近似各向同性，$K^\top K\approx(L_h/d)I$，则

$$W^*\approx\frac d{L_h}\sum_i v_i k_i^\top,\qquad W^*q\approx\frac d{L_h}\sum_i(k_i^\top q)v_i.\tag{A.3–A.4}$$

这是线性注意力式检索，没有 softmax 归一化；权重可为负，不能直接等同式 (A.1) 的凸组合。

**【未闭合点 1：有限步 SGD 不是闭式最优解】** 忽略视频损失时，一步更新为

$$W_1=W_0-2\eta c(W_0K^\top K-V^\top K).$$

即使 $W_0=0$ 且特征各向同性，要恰好等于上述最优解仍需特定步长 $2\eta c=d/L_h$；论文还加入视频预测梯度，实际用的是非线性 MLP，因此不能由这段线性分析推出部署网络“一步 SGD 就实现精确注意力”。附录 B 默认恰好 $N=1$，这一限制尤其值得说明。

**【未闭合点 2：组合目标不保证每项都下降】** $\mathcal L_{\rm vg}+\lambda\mathcal L_{\rm KVM}$ 的梯度下降不保证 KVM 单项下降，两个梯度可能冲突。附录 A 的解释提供设计直觉，并没有严格证明实际非线性网络等价 softmax 检索或泛化不下降。

**【维度备注】** 原文先采用行 token 的 $Q_r$ 记号，后又写 $W^*Q_r$；若查询批为 $Q_r\in\mathbb R^{L_r\times d}$，一致写法应为 $Q_r(W^*)^\top$；对单个列向量 $q\in\mathbb R^d$ 则 $W^*q$ 正确。
